# Alert Cue Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a second, independent kind of rule (an "alert rule") that, when a notification banner matches, records it and shows it in a persistent, manually-dismissed floating overlay card.

**Architecture:** A new `BannerScanner` does the shared per-pass AX work once (panel detection, banner-find, frame reads, text extraction, bundle resolution) and fans each `BannerObservation` out to independent `BannerHandler`s. `BannerMover` becomes one handler (repositioning); a new `AlertEvaluator` is the other (matches alert rules, dedups per window, appends in-memory `AlertEntry`s). `AlertOverlayController` renders the entries.

**Tech Stack:** Swift 5.10, SwiftPM two-target split (`BannerShiftCore` pure logic + `BannerShift` AppKit/AX executable), Swift Testing, AppKit, Accessibility.

**Design spec:** `docs/superpowers/specs/2026-05-24-alert-cue-design.md`

- The executable target (`Sources/BannerShift/`) has **no unit tests** by project convention; tasks 7-13 verify with `make build` / `make validate` plus the listed manual checks against a `make run` build.

```swift
import Foundation

/// The five optional regex patterns that define what a rule matches,
/// factored out of `Rule` so positioning rules and alert rules share one
/// matching surface and one compile/check implementation in `RuleMatcher`.
///
/// Each field is `nil`/empty == "match anything"; the patterns are
/// combined with logical AND at match time. Holding these together (rather
/// than re-declaring five fields per rule kind) keeps the intricate,
/// security-sensitive compile path in `RuleMatcher` as the single place a
/// matching bug can be fixed.
public struct MatchCriteria: Equatable, Sendable, Codable {
  public var appPattern: String?
  public var bundleIDPattern: String?
  public var titlePattern: String?
  public var subtitlePattern: String?
  public var bodyPattern: String?

  public init(
    appPattern: String? = nil,
    bundleIDPattern: String? = nil,
    titlePattern: String? = nil,
    subtitlePattern: String? = nil,
    bodyPattern: String? = nil
  ) {
    self.appPattern = appPattern
    self.bundleIDPattern = bundleIDPattern
    self.titlePattern = titlePattern
    self.subtitlePattern = subtitlePattern
    self.bodyPattern = bodyPattern
  }
}
```

- [ ] **Step 6: Refactor `RuleMatcher.swift`**

Replace the `match(rules:banner:)` method and the private `matches(_:_:)` method with:

```swift
  /// Returns the first enabled rule in `rules` whose patterns all match
  /// `banner`, or nil if no rule matches.
  ///
  /// Ordering is significant: callers control priority by ordering rules in
  /// the list. A rule with a malformed regex emits a diagnostic via the
  /// constructor-supplied logger and is treated as disabled for the
  /// duration of the call (so a broken rule never blocks later valid rules).
  public func firstMatch<R: Matchable>(in rules: [R], banner: BannerText) -> R? {
    for rule in rules where rule.enabled {
      do {
        if try matches(rule.criteria, banner) {
          return rule
        }
      } catch {
        diagnosticLogger?(
          "RuleMatcher: rule '\(rule.name)' (id=\(rule.id)) has a malformed "
            + "regex; treating as disabled. Error: \(error.localizedDescription)"
        )
        continue
      }
    }
    return nil
  }

  /// Convenience wrapper over `firstMatch` for positioning `Rule`s,
  /// returning a `RuleMatch` so existing callers are unaffected.
  public func match(rules: [Rule], banner: BannerText) -> RuleMatch? {
    firstMatch(in: rules, banner: banner).map(RuleMatch.init)
  }

  private func matches(_ criteria: MatchCriteria, _ banner: BannerText) throws -> Bool {
    try check(criteria.appPattern, banner.appName)
      && check(criteria.bundleIDPattern, banner.bundleID ?? "")
      && check(criteria.titlePattern, banner.title)
      && check(criteria.subtitlePattern, banner.subtitle)
      && check(criteria.bodyPattern, banner.body)
  }
```

(The `check`, `compiledRegex`, cache, and `compileForMatching` members are unchanged.)

```swift
import Foundation

/// A user-defined alert rule: the same matching surface as a positioning
/// `Rule` (via `MatchCriteria`) but with no position or animation. When a
/// banner matches, `AlertEvaluator` records an `AlertEntry` for the overlay
/// card instead of moving the banner.
///
/// Stored separately from positioning rules (`AlertRuleStore`) and edited in
/// its own window, so the two rule systems stay independent.
public struct AlertRule: Equatable, Sendable, Codable, Identifiable {
  /// Stable identifier across edits and reorderings.
  public let id: String

  /// User-facing label shown in the alert-rule editor and on a matched
  /// entry. Not used for matching.
  public var name: String

  /// When false, the matcher skips this rule entirely.
  public var enabled: Bool

  /// Patterns this rule matches against, AND-combined.
  public var criteria: MatchCriteria

  public init(
    id: String = UUID().uuidString,
    name: String = "",
    enabled: Bool = true,
    criteria: MatchCriteria = MatchCriteria()
  ) {
    self.id = id
    self.name = name
    self.enabled = enabled
    self.criteria = criteria
  }
}

extension AlertRule: Matchable {}
```

```swift
import Foundation

/// One recorded alert: a notification that matched an alert rule, distilled
/// to displayable text plus provenance.
///
/// Holds no Accessibility references, so it safely outlives the OS banner
/// and even a restart of the notification process. Deliberately **not**
/// `Codable`: alert entries are in-memory only and must never be written to
/// disk (notification content is sensitive).
public struct AlertEntry: Equatable, Sendable, Identifiable {
  public let id: String
  public let appName: String
  public let title: String
  public let body: String
  public let ruleName: String
  public let date: Date

  public init(
    id: String = UUID().uuidString,
    appName: String,
    title: String,
    body: String,
    ruleName: String,
    date: Date
  ) {
    self.id = id
    self.appName = appName
    self.title = title
    self.body = body
    self.ruleName = ruleName
    self.date = date
  }

  /// A single-line summary `"app · title: body"`, truncated to `maxLength`
  /// characters with a trailing ellipsis.
  ///
  /// The detail half collapses cleanly when fields are empty: title-only,
  /// body-only, or app-only. The leading bullet glyph is the view's concern
  /// and is not included here.
  public func oneLine(maxLength: Int) -> String {
    let detail: String
    switch (title.isEmpty, body.isEmpty) {
    case (false, false): detail = "\(title): \(body)"
    case (false, true): detail = title
    case (true, false): detail = body
    case (true, true): detail = ""
    }
    let full = detail.isEmpty ? appName : "\(appName) · \(detail)"
    return Self.truncate(full, to: maxLength)
  }

  private static func truncate(_ string: String, to maxLength: Int) -> String {
    guard maxLength > 0, string.count > maxLength else { return string }
    return String(string.prefix(maxLength - 1)) + "…"
  }
}
```

```swift
import Foundation

/// The ordered, newest-first set of currently-active alert entries.
///
/// A pure value type so its ordering and capacity behavior are unit-tested
/// in isolation; `AlertOverlayController` owns an instance and renders it.
/// There is no user-visible eviction (the card scrolls); a high safety cap
/// (`Constants.alertListSafetyCap`) bounds memory only against pathological
/// accumulation.
public struct AlertList: Equatable {
  /// Entries with the most recent at index 0.
  public private(set) var entries: [AlertEntry]

  public init() {
    entries = []
  }

  /// Insert `entry` at the front; drop the oldest if over the safety cap.
  public mutating func append(_ entry: AlertEntry) {
    entries.insert(entry, at: 0)
    if entries.count > Constants.alertListSafetyCap {
      entries.removeLast(entries.count - Constants.alertListSafetyCap)
    }
  }

  /// Remove the entry with the given id, if present.
  public mutating func dismiss(id: String) {
    entries.removeAll { $0.id == id }
  }

  /// Remove every entry.
  public mutating func dismissAll() {
    entries.removeAll()
  }
}
```

```swift
import Foundation

/// Persistence layer for the user's alert-rule list, backed by a single
/// JSON blob in `UserDefaults` under its own key.
///
/// Deliberately parallel to `RuleStore` rather than a shared generic: the
/// skeleton is small and the two stores are unlikely to diverge, so a
/// shared abstraction at two call sites would be premature indirection.
public final class AlertRuleStore {
  /// `UserDefaults` key under which the JSON-encoded alert-rule array lives.
  public static let key = "alertRules"

  private let defaults: UserDefaults
  private let logger: ((String) -> Void)?
  private let decoder = JSONDecoder()
  private let encoder = JSONEncoder()

  private var cachedRules: [AlertRule] = []
  private var hasLoaded = false

  public init(defaults: UserDefaults = .standard, logger: ((String) -> Void)? = nil) {
    self.defaults = defaults
    self.logger = logger
  }

  /// Return the persisted alert rules, or `[]` if none are saved or the
  /// blob fails to decode. Cached after the first call until `save(_:)`.
  public func load() -> [AlertRule] {
    if hasLoaded { return cachedRules }
    defer { hasLoaded = true }
    guard let data = defaults.data(forKey: Self.key) else {
      cachedRules = []
      return []
    }
    do {
      let rules = try decoder.decode([AlertRule].self, from: data)
      logger?("AlertRuleStore: loaded \(rules.count) alert rule(s) from defaults")
      cachedRules = rules
      return rules
    } catch {
      logger?("AlertRuleStore: failed to decode alert rules (\(error)); starting empty")
      cachedRules = []
      return []
    }
  }

  /// Encode `rules` and write the blob to defaults, updating the cache.
  /// Encoding failures are logged, not thrown, and leave the cache intact.
  public func save(_ rules: [AlertRule]) {
    do {
      let data = try encoder.encode(rules)
      defaults.set(data, forKey: Self.key)
      cachedRules = rules
      hasLoaded = true
    } catch {
```

```swift
import AppKit
import ApplicationServices
import BannerShiftCore

/// A single notification-UI window resolved to a banner, with everything a
/// handler needs: AX handles for repositioning and distilled `BannerText`
/// (bundle ID already resolved) for matching.
struct BannerObservation {
  let windowID: UInt64
  let window: AXUIElement
  let banner: AXUIElement
  let windowFrame: CGRect
  let bannerFrame: CGRect
  let text: BannerText
}

/// A consumer of the per-pass banner scan.
///
/// Named `BannerHandler` (not `…Observer`) to avoid confusion with the AX
/// `AXObserverController`. Handlers are independent: `BannerMover`
/// repositions, `AlertEvaluator` records alerts; neither references the
/// other. All callbacks run on the main thread.
protocol BannerHandler: AnyObject {
  /// A banner is present in this window this pass.
  func bannerPresent(_ observation: BannerObservation)
  /// This window has no banner to act on (a panel, or the banner is gone).
  func bannerAbsent(windowID: UInt64, window: AXUIElement)
  /// The notification UI process exited; AX-derived state is now invalid.
  func notificationUIDidReset()
}

/// Performs the shared per-pass AX work once per window (panel detection,
/// banner-find, frame reads, text extraction, bundle resolution) and fans
/// each result out to a fixed set of `BannerHandler`s.
///
/// This is the single owner of the window loop that previously lived in
/// `BannerMover`; hoisting it here means the expensive, OS-fragile AX reads
/// happen exactly once even with multiple handlers. Main-thread only.
final class BannerScanner {
  private let handlers: [BannerHandler]

  init(handlers: [BannerHandler]) {
    self.handlers = handlers
  }

  /// Classify each window and fan the result out to every handler.
  func process(notificationUIWindows windows: [AXUIElement]) {
    for window in windows {
      let id = elementID(window)

      if NotificationCenterPanelDetector.isPanel(window) {
        notifyAbsent(id: id, window: window)
        continue
      }

      guard let banner = AXBannerFinder.find(in: window),
        let bannerFrame = AXBannerFinder.frame(of: banner),
        let windowFrame = AXBannerFinder.frame(of: window)
      else {
        notifyAbsent(id: id, window: window)
        continue
      }

      var text = BannerTextExtractor.extract(from: banner)
      if let bundleID = AppResolver.bundleID(forAppName: text.appName) {
        text = BannerText(
          appName: text.appName,
          bundleID: bundleID,
          title: text.title,
          subtitle: text.subtitle,
          body: text.body)
      }

      let observation = BannerObservation(
        windowID: id,
        window: window,
        banner: banner,
        windowFrame: windowFrame,
        bannerFrame: bannerFrame,
        text: text)
      for handler in handlers { handler.bannerPresent(observation) }
    }
  }

  /// Notify every handler that AX-derived state is now invalid.
  func reset() {
    for handler in handlers { handler.notificationUIDidReset() }
  }

  private func notifyAbsent(id: UInt64, window: AXUIElement) {
    for handler in handlers { handler.bannerAbsent(windowID: id, window: window) }
  }

  private func elementID(_ element: AXUIElement) -> UInt64 {
    UInt64(UInt(bitPattern: Unmanaged.passUnretained(element).toOpaque()))
  }
}
```

## Task 9: Add `AlertEvaluator`

**Files:**
- Create: `Sources/BannerShift/Repositioning/AlertEvaluator.swift`

- [ ] **Step 1: Create `AlertEvaluator.swift`**

```swift
import AppKit
import ApplicationServices
import BannerShiftCore
import Foundation

/// `BannerScanner` handler that turns alert-rule matches into `AlertEntry`s.
///
/// Dedups per window: a banner is processed many times before it dismisses,
/// so at most one entry is emitted per banner appearance (keyed by window
/// id). The dedup key is cleared when the banner goes away, so a later
/// banner reusing that window id can alert again. Emitted entries hold no AX
/// references, so `notificationUIDidReset` clears only the dedup set, never
/// the user-facing entries. Main-thread only.
final class AlertEvaluator: BannerHandler {
  private let matcher: RuleMatcher
  private let alertRuleStore: AlertRuleStore
  private let logger: FileLogger
  private let onAlert: (AlertEntry) -> Void
  private var alertedWindowIDs: Set<UInt64> = []

  /// - Parameter onAlert: invoked on the main thread with a new entry when a
  ///   banner first matches an alert rule. Wired to the overlay controller.
  init(
    matcher: RuleMatcher,
    alertRuleStore: AlertRuleStore,
    logger: FileLogger,
    onAlert: @escaping (AlertEntry) -> Void
  ) {
    self.matcher = matcher
    self.alertRuleStore = alertRuleStore
    self.logger = logger
    self.onAlert = onAlert
  }

  func bannerPresent(_ observation: BannerObservation) {
    guard !alertedWindowIDs.contains(observation.windowID) else { return }
    guard let rule = matcher.firstMatch(in: alertRuleStore.load(), banner: observation.text)
    else { return }

    alertedWindowIDs.insert(observation.windowID)
    let entry = AlertEntry(
      appName: observation.text.appName,
      title: observation.text.title,
      body: observation.text.body,
      ruleName: rule.name,
      date: Date())
    onAlert(entry)
    logger.debug(
      "AlertEvaluator: alert rule '\(rule.name)' matched window "
        + "\(String(format: "%016llx", observation.windowID))")
  }

  func bannerAbsent(windowID: UInt64, window: AXUIElement) {
    alertedWindowIDs.remove(windowID)
  }

  func notificationUIDidReset() {
    // Only AX-keyed dedup state is invalid; emitted entries persist until
    // the user dismisses them.
    alertedWindowIDs.removeAll()
  }
}
```

```swift
import AppKit
import BannerShiftCore

/// The editing controls shared by both rule editors: a name field, an
/// enabled checkbox, and the five regex fields with live validation against
/// `RuleMatcher.compileForMatching`.
///
/// Emits the current values via `onChange` whenever a field commits, so each
/// editor can fold them back into its own rule kind. Knows nothing about
/// position, animation, or persistence. Main-thread only.
final class RulePatternFormView: NSView {
  /// Snapshot of the form's editable values.
  struct Values {
    var name: String
    var enabled: Bool
    var criteria: MatchCriteria
  }

  var onChange: ((Values) -> Void)?

  private let nameField = NSTextField()
  private let enabledButton = NSButton(checkboxWithTitle: "Enabled", target: nil, action: nil)
  private let appField = NSTextField()
  private let bundleField = NSTextField()
  private let titleField = NSTextField()
  private let subtitleField = NSTextField()
  private let bodyField = NSTextField()
  private let appError = NSTextField(labelWithString: "")
  private let bundleError = NSTextField(labelWithString: "")
  private let titleError = NSTextField(labelWithString: "")
  private let subtitleError = NSTextField(labelWithString: "")
  private let bodyError = NSTextField(labelWithString: "")

  override init(frame frameRect: NSRect) {
    super.init(frame: frameRect)
    buildUI()
  }

  required init?(coder: NSCoder) { fatalError("init(coder:) not supported") }

  /// Populate the fields from `values` (or clear and disable when nil).
  func load(_ values: Values?) {
    let enabled = values != nil
    for control in [
      nameField, enabledButton, appField, bundleField, titleField, subtitleField, bodyField,
    ] as [NSControl] {
      control.isEnabled = enabled
    }
    guard let values else {
      nameField.stringValue = ""
      enabledButton.state = .off
      for field in [appField, bundleField, titleField, subtitleField, bodyField] {
        field.stringValue = ""
      }
      clearValidation()
      return
    }
    nameField.stringValue = values.name
    enabledButton.state = values.enabled ? .on : .off
    appField.stringValue = values.criteria.appPattern ?? ""
    bundleField.stringValue = values.criteria.bundleIDPattern ?? ""
    titleField.stringValue = values.criteria.titlePattern ?? ""
    subtitleField.stringValue = values.criteria.subtitlePattern ?? ""
    bodyField.stringValue = values.criteria.bodyPattern ?? ""
    validateAll()
  }

  private func currentValues() -> Values {
    Values(
      name: nameField.stringValue,
      enabled: enabledButton.state == .on,
      criteria: MatchCriteria(
        appPattern: nilIfEmpty(appField.stringValue),
        bundleIDPattern: nilIfEmpty(bundleField.stringValue),
        titlePattern: nilIfEmpty(titleField.stringValue),
        subtitlePattern: nilIfEmpty(subtitleField.stringValue),
        bodyPattern: nilIfEmpty(bodyField.stringValue)))
  }

  private func buildUI() {
    nameField.placeholderString = "Rule name"
    nameField.delegate = self
    enabledButton.target = self
    enabledButton.action = #selector(commit)
    for field in [appField, bundleField, titleField, subtitleField, bodyField] {
      field.delegate = self
      field.placeholderString = "regex (empty = wildcard)"
    }
    for err in [appError, bundleError, titleError, subtitleError, bodyError] {
      err.textColor = .systemRed
      err.font = .systemFont(ofSize: 10)
    }

    func row(_ label: String, _ control: NSView, _ err: NSView? = nil) -> NSStackView {
      let labelView = NSTextField(labelWithString: label)
      labelView.alignment = .right
      labelView.widthAnchor.constraint(equalToConstant: 90).isActive = true
      var subs: [NSView] = [labelView, control]
      if let err { subs.append(err) }
      let stack = NSStackView(views: subs)
      stack.orientation = .horizontal
      stack.spacing = 6
      return stack
    }

    let stack = NSStackView(views: [
      row("Name:", nameField),
      row("", enabledButton),
      row("App:", appField, appError),
      row("Bundle ID:", bundleField, bundleError),
      row("Title:", titleField, titleError),
      row("Subtitle:", subtitleField, subtitleError),
      row("Body:", bodyField, bodyError),
    ])
    stack.orientation = .vertical
    stack.alignment = .leading
    stack.spacing = 6
    stack.translatesAutoresizingMaskIntoConstraints = false
    addSubview(stack)
    NSLayoutConstraint.activate([
      stack.leadingAnchor.constraint(equalTo: leadingAnchor),
      stack.trailingAnchor.constraint(equalTo: trailingAnchor),
      stack.topAnchor.constraint(equalTo: topAnchor),
      stack.bottomAnchor.constraint(equalTo: bottomAnchor),
    ])
  }

  @objc private func commit() {
    validateAll()
    onChange?(currentValues())
  }

  // MARK: Validation

  private func validateAll() {
    validate(appField, into: appError)
    validate(bundleField, into: bundleError)
    validate(titleField, into: titleError)
    validate(subtitleField, into: subtitleError)
    validate(bodyField, into: bodyError)
  }

  private func validate(_ field: NSTextField, into err: NSTextField) {
    field.wantsLayer = true
    let pattern = field.stringValue
    if pattern.isEmpty {
      field.layer?.borderWidth = 0
      err.stringValue = ""
      return
    }
    do {
      _ = try RuleMatcher.compileForMatching(pattern)
      field.layer?.borderWidth = 0
      err.stringValue = ""
    } catch {
      field.layer?.borderColor = NSColor.systemRed.cgColor
      field.layer?.borderWidth = 1
      err.stringValue = "Invalid regex"
    }
  }

  private func clearValidation() {
    for (field, label) in [
      (appField, appError), (bundleField, bundleError), (titleField, titleError),
      (subtitleField, subtitleError), (bodyField, bodyError),
    ] {
      field.layer?.borderWidth = 0
      label.stringValue = ""
    }
  }

  private func nilIfEmpty(_ value: String) -> String? { value.isEmpty ? nil : value }
}

extension RulePatternFormView: NSTextFieldDelegate {
  func controlTextDidChange(_ obj: Notification) {
    guard let field = obj.object as? NSTextField else { return }
    switch field {
    case appField: validate(appField, into: appError)
    case bundleField: validate(bundleField, into: bundleError)
    case titleField: validate(titleField, into: titleError)
    case subtitleField: validate(subtitleField, into: subtitleError)
    case bodyField: validate(bodyField, into: bodyError)
    default: break
    }
  }

  func controlTextDidEndEditing(_ obj: Notification) {
    commit()
  }
}
```

```swift
import AppKit
import BannerShiftCore

/// Window controller for the alert-rule editor: a list of alert rules plus
/// the shared pattern form. Writes back to `AlertRuleStore` on every change
/// (no Save button), matching the positioning editor's behavior.
final class AlertRuleEditorWindowController: NSWindowController {
  private let alertRuleStore: AlertRuleStore
  private var rules: [AlertRule] = []
  private var selectedIndex: Int?

  private let tableView = NSTableView()
  private let addButton = NSButton(title: "Add", target: nil, action: nil)
  private let removeButton = NSButton(title: "Remove", target: nil, action: nil)
  private let form = RulePatternFormView()

  init(alertRuleStore: AlertRuleStore) {
    self.alertRuleStore = alertRuleStore
    let window = NSWindow(
      contentRect: NSRect(x: 0, y: 0, width: 620, height: 420),
      styleMask: [.titled, .closable],
      backing: .buffered,
      defer: false)
    window.title = "BannerShift Alert Rules"
    window.isReleasedWhenClosed = false
    window.center()
    super.init(window: window)
    rules = alertRuleStore.load()
    buildUI()
    refreshTable()
    loadFormForSelection()
  }

  required init?(coder: NSCoder) { fatalError("init(coder:) not supported") }

  /// Bring the editor window to the front.
  func show() {
    window?.makeKeyAndOrderFront(nil)
    NSApp.bringToFront()
  }

  private func buildUI() {
    guard let content = window?.contentView else { return }
    configureTable()
    addButton.target = self
    addButton.action = #selector(addRule)
    removeButton.target = self
    removeButton.action = #selector(removeRule)
    let listButtons = NSStackView(views: [addButton, removeButton])
    listButtons.orientation = .horizontal
    let scroll = NSScrollView()
    scroll.documentView = tableView
    scroll.hasVerticalScroller = true
    scroll.borderType = .bezelBorder
    let leftStack = NSStackView(views: [scroll, listButtons])
    leftStack.orientation = .vertical
    leftStack.alignment = .leading
    leftStack.spacing = 6

    form.onChange = { [weak self] values in self?.formChanged(values) }
    form.translatesAutoresizingMaskIntoConstraints = false

    let top = NSStackView(views: [leftStack, form])
    top.orientation = .horizontal
    top.distribution = .fillEqually
    top.spacing = 16
    top.alignment = .top
    top.edgeInsets = NSEdgeInsets(top: 12, left: 12, bottom: 12, right: 12)
    top.translatesAutoresizingMaskIntoConstraints = false
    content.addSubview(top)
    NSLayoutConstraint.activate([
      top.leadingAnchor.constraint(equalTo: content.leadingAnchor),
      top.trailingAnchor.constraint(equalTo: content.trailingAnchor),
      top.topAnchor.constraint(equalTo: content.topAnchor),
      top.bottomAnchor.constraint(equalTo: content.bottomAnchor),
      scroll.widthAnchor.constraint(greaterThanOrEqualToConstant: 240),
      scroll.heightAnchor.constraint(greaterThanOrEqualToConstant: 300),
    ])
  }

  private func configureTable() {
    let onCol = NSTableColumn(identifier: NSUserInterfaceItemIdentifier("on"))
    onCol.title = "On"
    onCol.width = 40
    let nameCol = NSTableColumn(identifier: NSUserInterfaceItemIdentifier("name"))
    nameCol.title = "Name"
    nameCol.width = 180
    tableView.addTableColumn(onCol)
    tableView.addTableColumn(nameCol)
    tableView.dataSource = self
    tableView.delegate = self
    tableView.allowsEmptySelection = true
    tableView.target = self
    tableView.action = #selector(tableSelectionChanged(_:))
  }

  private func refreshTable() {
    tableView.reloadData()
    if let index = selectedIndex, rules.indices.contains(index) {
      tableView.selectRowIndexes(IndexSet(integer: index), byExtendingSelection: false)
    }
  }

  private func loadFormForSelection() {
    let rule = selectedIndex.flatMap { rules.indices.contains($0) ? rules[$0] : nil }
    form.load(rule.map { RulePatternFormView.Values(name: $0.name, enabled: $0.enabled, criteria: $0.criteria) })
  }

  private func formChanged(_ values: RulePatternFormView.Values) {
    guard let index = selectedIndex, rules.indices.contains(index) else { return }
    var rule = rules[index]
    rule.name = values.name
    rule.enabled = values.enabled
    rule.criteria = values.criteria
    rules[index] = rule
    alertRuleStore.save(rules)
    tableView.reloadData(
      forRowIndexes: IndexSet(integer: index),
      columnIndexes: IndexSet(integersIn: 0..<tableView.tableColumns.count))
  }

  @objc private func tableSelectionChanged(_ sender: NSTableView) {
    selectedIndex = tableView.selectedRow >= 0 ? tableView.selectedRow : nil
    loadFormForSelection()
  }

  @objc private func addRule() {
    rules.append(AlertRule(name: "New Alert"))
    selectedIndex = rules.count - 1
    alertRuleStore.save(rules)
    refreshTable()
    loadFormForSelection()
  }

  @objc private func removeRule() {
    guard let index = selectedIndex, rules.indices.contains(index) else { return }
    rules.remove(at: index)
    selectedIndex = rules.isEmpty ? nil : min(index, rules.count - 1)
    alertRuleStore.save(rules)
    refreshTable()
    loadFormForSelection()
  }
}

extension AlertRuleEditorWindowController: NSTableViewDataSource {
  func numberOfRows(in tableView: NSTableView) -> Int { rules.count }
}

extension AlertRuleEditorWindowController: NSTableViewDelegate {
  func tableView(
    _ tableView: NSTableView, viewFor tableColumn: NSTableColumn?, row: Int
  ) -> NSView? {
    let rule = rules[row]
    switch tableColumn?.identifier.rawValue {
    case "on":
      let button = NSButton(
        checkboxWithTitle: "", target: self, action: #selector(rowEnabledToggled(_:)))
      button.state = rule.enabled ? .on : .off
      button.tag = row
      return button
    case "name":
      return NSTextField(labelWithString: rule.name)
    default:
      return nil
    }
  }

  @objc private func rowEnabledToggled(_ sender: NSButton) {
    let row = sender.tag
    guard rules.indices.contains(row) else { return }
    rules[row].enabled = sender.state == .on
    alertRuleStore.save(rules)
    if selectedIndex == row { loadFormForSelection() }
  }
}
```
